# 政委晨间日报 · 2026-11-22

## 今日一点

周日了，上场时段还没开始，日历却已经靠近下周的边。这几天谈的是把水准线走稳：小错之后复位、触线即交付、注意放在过程上，也不把结尾写成整周的终审；昨天说的是场下让监测班下场。今天更容易踩的坑，不是又把监视岗排回来，而是把「明天翻页」写成一次重生——新的一周必须从第一刀起就干净，必须用开局证明自己还能走稳。Hengchen Dai、Katherine Milkman 与 Jason Riis 所说的新开始效应（fresh start effect）指的就是这种时间界标（temporal landmark）带来的断裂感：周一、新的一周、新的一份日历，会让人觉得与「上周那个会滑的自己」已经分开，于是把抱负重新加码，把开局写成新账户的第一笔。动机会被抬起来，标准却也常常被一并抬高。要开局零瑕疵，注意就会提前盯着「别在第一刀滑」；要把新的一周打成证明周，第一刀就不再是同一条水准线上的普通一刀，而成了整周的入场券。两条路都会把方差做大。少犯非受迫性失误、压住回撤，靠的不是每周开一个新账户，而是让翻页之后仍走同一条水准线：标准不重写，开局不加码。日历会换页，水准线不重启。

## 落地提醒

1. 开场先写清今天的场地：周日不是下周的起草室。若有必须停泊给周一的事，只写一件「周一第一刀」，收口标准对准上周同一条水准线，不要写成「新一周必须开得干净」「用开局证明这周能走稳」「把整周蓝图今天一次定完」。写完这一句，把其余的下周设计从桌上拿开，注意回到今天这块场地。
2. 当途中冒出「明天是新的一周，必须从第一刀就别滑／这周得开成证明周才算数／周日应该先把新周的自己设计好／上周有过瑕疵，正好用周一清零再来」，先贴标签：「这是新开始效应，是时间界标在给开局加码，不是标准该重写，也不是今天必须把下周起草完。」然后只问一句：「周一第一刀的收口标准，还是不是原来那条水准线？」是，就停泊到开刀的时间，注意回到今天；不是，把加码划掉，改回原标准，再停泊。不要在周日给新的一周另开一个账户。
3. 今天只守一个动作：翻页不重启。每逢「新周必须干净开局／把周日写成起草室／用开局证明自己」的念头冒出来，记「同一条水准线／新账户加码」二选一。为了让周一重生、开局零瑕疵、或把整周蓝图一次定完而在今天加戏，记作没守住。不要把「不重启」听成周一可以随便开——标准不降，也不因日历翻页而抬高。

## 收束

政委不跟你谈「周日必须把下周设计完美，或者今天完全不要想周一才算放过自己」。政委帮你挡住开局加码：长期少犯非受迫性失误，靠的不是每周开一个新账户，而是翻页之后仍走同一条水准线。时间界标会让人想重生；水准线靠的是连续，不是清零。周日交的是今天这一格，不是下周的入场仪式。

——政委
