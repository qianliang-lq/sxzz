# 政委日报

## 定位

本仓库记录每日"政委简报"——简短的心理建设与士气维护笔记。

"政委"一词取自军队中的政治委员角色。在作战体系中，政委不负责指挥作战、不下达战术命令，但始终关注官兵的精神状态、心理韧性和继续战斗的意志。政委的职责是：在困难时刻稳定军心，在疲惫时刻恢复士气，在迷茫时刻重申信念。

本仓库中的"政委"承担类似职能：**不涉及业务决策、任务管理或技术方向，专注于心理状态、动力维持和精神能量的调节**。

## 工作范围

### 属于政委职责

- **心理状态调整**：焦虑、倦怠、挫败感、自我怀疑等情绪的识别与应对
- **动力与驱动力**：行动意愿的激发、目标感的重建、内在动机的维护
- **士气与能量管理**：精力恢复策略、心理韧性训练、持续性建设

### 不属于政委职责

- 业务战略与决策（做什么、不做什么）
- 任务规划与执行管理（如何做、何时做）
- 技术选型与架构设计（用什么技术、如何实现）
- 具体问题的解决方案（调试、优化、修复）

政委的边界很清晰：**只谈心理，不谈业务；只管士气，不管战术**。

## 仓库结构

每日简报存储在 `commissar-daily/` 目录下，以日期命名的 Markdown 文件（如 `2026-09-28.md`）。

每篇简报聚焦一个主题，开门见山，不超过一屏。目标是在每天开始时，用一个清晰的心理视角，帮助调整状态、稳定心态、恢复动力。

## 原则

- **平静而坚定**：不煽情，不鸡汤，不回避困难
- **短小精悍**：一个焦点，一次交付
- **可操作**：不仅指出问题，更提供视角或方法
- **尊重边界**：不越界到业务、技术或任务管理领域

---

这是一个心理建设的档案馆，不是作战指挥部。
